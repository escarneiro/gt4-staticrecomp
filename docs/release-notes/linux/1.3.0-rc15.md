# GT4Recomp 1.3.0-rc15 for Linux (AppImage)

> **Test build of the Linux port.** One file with the launcher and both games, built from the 1.3.0-rc15 game code with the
> Linux port (TASK-074). Tested on one machine so far (openSUSE Tumbleweed, AMD Radeon RX 6600). Not an official GT4Recomp
> release: this comes from a fork.

**The launcher and both games (Gran Turismo 4 v2.00 and Spec II) run natively on Linux: Vulkan renderer CoreGS 2.0, SDL3
window, sound, keyboard, controllers and racing wheels, with the 1.3.0-rc15 game code (PGO and ThinLTO builds). Saves work
like the memory cards of an emulator.**

## Install

1. Download `GT4Recomp-1.3.0-rc15-x86_64.AppImage` (check it against `SHA256SUMS`: `sha256sum -c SHA256SUMS`).
2. Make it executable: `chmod +x GT4Recomp-1.3.0-rc15-x86_64.AppImage`, then start it (double-click or from a terminal).
3. Setup asks for your own disc image (`.iso`) of Gran Turismo 4 (SCUS-97328) or Spec II (SCUS-97436). The image stays where
   you keep it; nothing is copied. Then choose a new game or import a save (`.ps2`, `.psu`, `.mcd`, `.bin`).

You supply the game: the AppImage contains no game data, only programs built from it.

## Requirements

- **x86-64 Linux with glibc 2.43 or newer** (the programs are built on openSUSE Tumbleweed): current rolling distributions
  such as Tumbleweed or Arch. Ubuntu 24.04 and Debian 13 are too old for this build.
- A **Vulkan 1.2** (or newer) graphics card and driver (Mesa RADV tested), and FUSE (`fusermount`) to mount the AppImage,
  or run it with `--appimage-extract-and-run`.
- Wayland or X11, PipeWire or PulseAudio.

## Where your files go

Settings, controls, saves, replays, logs and the prepared game files are in `~/.local/share/GT4Recomp`
(`$XDG_DATA_HOME/GT4Recomp` when that is set): `user/` (settings and the save library, `user/games/<game>/Saves`) and `data/`.
The AppImage itself is read-only and can be moved or replaced freely.

## What works

- Both games from the launcher: setup from your disc image, Play, and the launcher's Settings pages (graphics, controls,
  wheel).
- Renderer **CoreGS 2.0** only (GSdx, the PCSX2 renderer of the Windows build, is not part of the Linux port).
- Keyboard, controllers through SDL3 (a DualShock 4 is tested: buttons, sticks, triggers, rumble), fullscreen.
- Racing wheels through the virtual Driving Force Pro with force feedback (a Logitech G29 is tested).
- Frame skip (60 and 30 FPS), the memory card written back after each session, the F7/F8/F9 performance report.
- **Saves like memory cards:** each folder in `Saves` is a save named like its folder; the marked one is the one Play uses;
  New save, rename, export (`.psu`) and delete on the Saves page; setup asks for a new game or an imported save.

## Known limits

- **No automatic updates.** A new version is a new AppImage file; download it and use it in place of the old one (your files
  stay in `~/.local/share/GT4Recomp`).
- RetroAchievements and Discord Rich Presence are not available on Linux yet.
- Two launchers can be started at once (there is no single-instance lock on Linux yet); start one.
- The launcher ignores the terminal's stop signal (Ctrl+C); close it from its window.
- Only one machine has tested this build; other GPUs, controllers and distributions are untested.

## Build

- Game programs: `gt4_linux_window` PGO builds of v2.00 and Spec II from the rc15 code (`task/074-linux-host-build`).
- Launcher: GT4Recomp 1.3.0-rc15, AppImage build (`cargo tauri build --bundles appimage --features appimage`).
- Script: `scripts/linux/appimage.sh` and `scripts/linux/release.sh` (notes in `docs/linux/L4-APPIMAGE.md`).
- The full notes of the 1.3.0-rc15 game code (shared with the Windows build) are in `docs/release-notes/1.3.0-rc15.md`.
